# Значки

Значок — маленькая метка у имени в списке чатов и в профиле. Это украшение, а
не подтверждение чего-либо: кто соберёт свой форк, впишет туда своих людей. Так
было, пока список лежал внутри приложения, и переезд в этот репозиторий этого
не меняет.

## Файл

[badges.json](../badges.json) в ветке `main`. Приложение перечитывает его при
каждом запуске, поэтому дописать строчку здесь достаточно — ни новой сборки, ни
обновления не нужно.

```json
[
  {
    "peer": 7826361017,
    "title": "Margelet creator",
    "title_ru": "Создатель Margelet",
    "about": "Made this fork.",
    "about_ru": "Сделал этот форк.",
    "color": "8DD1B0",
    "url": "https://t.me/narezanyinf"
  }
]
```

| | |
|---|---|
| `peer` | кому. У человека — его номер, у канала или группы тот же номер со знаком минус |
| `title` | название: стоит у имени и заголовком в окне |
| `about` | одна строка внутри окна |
| `color` | цвет поля, шестнадцатеричный — годятся `8DD1B0`, `#8DD1B0` и `FF8DD1B0` |
| `url` | куда ведёт кнопка в окне. Не написали — кнопки нет |

Переводы — те же ключи с `_ru` или `_zh`. Нет перевода — берётся основной,
поэтому значок с одним только `title` работает везде.

У одного человека значков может быть несколько. У имени стоит первый
подходящий по файлу, то есть порядок в файле и есть старшинство. В профиле
показываются все.

## Цвета

Картинка одна — самолётик форка, — а поле под ней красится в тот цвет, что
написан в `color`. Поэтому новому значку не нужна новая картинка: пишешь
`E09A9A`, и поле розовое.

## Если файл не доехал

Список кэшируется. Без сети показывается последний скачанный, а пока файл не
скачался ни разу — тот, что вшит в приложение. На свежей установке без
интернета всё выглядит ровно так, как выглядело раньше.

Строка, которую не удалось разобрать, пропускается, а файл, который не
разобрался целиком, оставляет прошлый список на месте: из-за одной опечатки ни
у кого не должны пропасть значки.
