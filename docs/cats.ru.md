# Коты

Кот — картинка на весь экран, которую форк показывает по своему поводу. Раньше
их было ровно два, и оба лежали в сборке: чтобы добавить третьего, надо было
собрать клиент заново и раздать его всем. Теперь список лежит здесь, как и
[значки](badges.ru.md).

## Файл

[cats.json](../cats.json) в ветке `main`. Приложение перечитывает его не чаще
раза в десять минут — коты не новости, а ходить в сеть на каждый показ значит
ходить в неё зря.

```json
[
  {
    "photo": "res/margelet_cat_1.jpg",
    "name": "Murzik",
    "name_ru": "Мурзик",
    "from": "@narezany"
  }
]
```

| | |
|---|---|
| `photo` | путь к картинке в этом репозитории или полный адрес |
| `name` | кличка |
| `from` | чей кот. Показывается подписью |

Переводы — те же ключи с `_ru` или `_zh`, как у значков. Нет перевода — берётся основной.

## Картинки

Картинка приезжает отдельно от списка и своим путём: восемь мегабайт потолок и
запись через временный файл, чтобы оборванная закачка не оставила полкартинки,
которую потом покажут как целую.

Пока картинка едет, показывается кот, вшитый в сборку, а не пустое место.

## Если файл не доехал

Скачанный список лежит рядом с приложением и переживает отсутствие сети. Пока
файл не скачался ни разу, работают два вшитых кота — на свежей установке без
интернета всё выглядит как раньше.

Строка, которую не удалось разобрать, пропускается, а файл, который не
разобрался целиком, оставляет прошлый список на месте.
