Плагины Margelet

Плагин — это код на питоне, который выполняется внутри форка. Не отдельная программа, не бот со стороны: он живёт в том же приложении, что и переписка.

Правило форума

Код плагина не обфусцируется. Он едет исходником, и открыть его должен мочь любой. Обфускация — бан на форуме.

Причина простая: песочницы здесь нет. Проверить, что плагин делает, можно только одним способом — прочитать его. Спрятанный код лишает этой возможности всех сразу.

Честно про безопасность

Плагин может всё, что может само приложение: читать переписку, писать от вашего имени, лезть в файлы. Разрешения в манифесте — заявление автора, а не ограничение; приложение их не проверяет и проверить не может.

Ставьте только то, что прочитали сами или чему доверяете.

Формат .marp

Обычный zip, переименованный в .marp:

margelet_example.marp
├── manifest.json   обязательно
├── main.py         обязательно
├── icon.png        по желанию
└── ...             всё остальное, что нужно плагину

manifest.json

{
  "id": "margelet.example",
  "name": "Пример",
  "version": "1.0",
  "author": "narezany",
  "description": "Здоровается в консоли.",
  "permissions": ["ui"]
}
ПолеЧто это
idНомер плагина. Латиницей, с точками. По нему плагин обновляется и хранит настройки — менять нельзя.
nameИмя в списке.
versionВерсия, строкой.
authorКто написал.
descriptionОдна-две строки: что делает.
permissionsЧто плагин о себе заявляет. Список ниже.

Разрешения: read_chats, send_messages, edit_messages, delete_messages, change_profile, ui. Своё имя тоже можно — оно покажется как есть.

main.py

def on_start():
    margelet.log("привет из плагина", margelet.name)

on_start() вызывается при запуске плагина. Если его нет, плагин просто выполняется сверху вниз.

Объект margelet доступен без импорта:

margelet.idномер из манифеста
margelet.nameимя из манифеста
margelet.folderпапка плагина на телефоне
margelet.log(*части)строка в консоль
margelet.error(*части)то же, но красным

print() тоже уходит в консоль — перехвачен.

Что доступно кроме этого

Питон здесь настоящий, с доступом к java-классам приложения:

from java import jclass

Config = jclass("org.telegram.margelet.MargeletConfig")
margelet.log("ватермарка:", Config.watermarkOnSend())

Отсюда достаётся всё остальное приложение. Это и есть «плагин может всё» — не оборот речи.

Консоль

Настройки → Margelet → Плагины → Консоль. Туда уходит вся печать плагинов и их ошибки, ошибки красным. Питон падает молча, так что без консоли о своей опечатке автор узнаёт только по тому, что «ничего не работает».

Установка

Настройки → Margelet → Плагины → Установить из файла. На окне установки видно автора и заявленные разрешения.

Новый плагин ставится выключенным. Включается нажатием на строку, долгое нажатие — карточка и удаление.

Выключение значит «больше не запускать». Уже работающий питоновский код остановить нечем — он доживёт до перезапуска приложения.

Пример

margelet_example.marp — тот же, что лежит в приложении с самого начала. Внутри две строки, начать можно с них.
