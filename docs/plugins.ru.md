# Плагины Margelet

[English](plugins.md) · **Русский** · [中文](plugins.zh.md)

Плагин — это код на питоне, который выполняется внутри форка. Не отдельная
программа, не бот со стороны: он живёт в том же приложении, что и переписка.

## Правило форума

**Код плагина не обфусцируется.** Он едет исходником, и открыть его должен
мочь любой. Обфускация — бан на форуме.

Причина простая: песочницы здесь нет. Проверить, что плагин делает, можно
только одним способом — прочитать его. Спрятанный код лишает этой
возможности всех сразу.

## Честно про безопасность

Плагин может всё, что может само приложение: читать переписку, писать от
вашего имени, лезть в файлы. Разрешения в манифесте — **заявление автора**, а
не ограничение; приложение их не проверяет и проверить не может.

Ставьте только то, что прочитали сами или чему доверяете.

## Формат .marp

Обычный zip, переименованный в `.marp`:

```
margelet_example.marp
├── manifest.json   обязательно
├── main.py         обязательно
├── icon.png        по желанию
└── ...             всё остальное, что нужно плагину
```

`icon.png` показывается в списке плагинов. Картинка квадратная, 128×128 хватит.

## manifest.json

```json
{
  "id": "margelet.example",
  "name": "Пример",
  "version": "1.0",
  "author": "narezany",
  "description": "Здоровается в консоли.",
  "min_version": "0.3",
  "permissions": ["ui"]
}
```

| Поле | Что это |
|---|---|
| `id` | Номер плагина. Латиницей, с точками. По нему плагин обновляется и хранит настройки — менять нельзя. |
| `name` | Имя в списке. |
| `version` | Версия, строкой. |
| `author` | Кто написал. |
| `description` | Одна-две строки: что делает. |
| `min_version` | Самая старая версия Margelet, на которой плагин работает. На версии старее он не поставится вовсе — с объяснением, а не молча. Поле необязательное. |
| `permissions` | Что плагин о себе заявляет. Список ниже. |
| `name_en`, `name_zh`, `description_en`, … | То же на другом языке. Приложение возьмёт по своему языку, а нет перевода — возьмёт обычное поле. |

Разрешения: `read_chats`, `send_messages`, `edit_messages`,
`delete_messages`, `change_profile`, `ui`. Своё имя тоже можно — оно покажется
как есть.

## main.py

```python
def on_start():
    margelet.log("привет из плагина", margelet.name)
```

`on_start()` вызывается при запуске плагина. Если его нет, плагин просто
выполняется сверху вниз.

Объект `margelet` доступен без импорта:

| | |
|---|---|
| `margelet.id` | номер из манифеста |
| `margelet.name` | имя из манифеста |
| `margelet.folder` | папка плагина на телефоне |
| `margelet.log(*части)` | строка в консоль |
| `margelet.error(*части)` | то же, но красным |
| `margelet.ui(вызов, delay_ms=0)` | выполнить на главном потоке — всё, что трогает экран, только оттуда |
| `margelet.every(мс, вызов)` | повторять каждые `мс`. Возвращает ручку |
| `margelet.cancel(ручка)` | прекратить повтор |
| `margelet.toast(текст)` | короткая надпись поверх экрана |
| `margelet.get(ключ, запасное=None)` | своя память плагина |
| `margelet.set(ключ, значение)` | записать в неё |
| `margelet.flag(ключ, запасное=False)` | прочитать переключатель с экрана настроек как да/нет |
| `margelet.background(вызов)` | сделать что-то долгое в стороне от экрана |
| `margelet.send(чат, текст)` | отправить сообщение в переписку |
| `margelet.fetch(адрес, вызов)` | сходить в сеть и позвать `вызов(текст)`; не получилось — `None` |
| `margelet.activity()` | текущий экран приложения |
| `margelet.window(заголовок, вид)` | показать своё окно в оформлении приложения |
| `margelet.color(0xFFRRGGBB)` | цвет в том виде, в каком его понимает андроид |

`get` и `set` переживают и перезапуск, и обновление самого плагина: они лежат
не в папке плагина, а её при обновлении заменяют.

## События

Плагин не опрашивает приложение — приложение зовёт плагин.

| | |
|---|---|
| `margelet.on_chat_opened(вызов)` | открыли переписку; передадут сам экран |
| `margelet.on_send(вызов)` | человек отправляет текст, до отправки |
| `margelet.on_message(вызов)` | пришло сообщение |
| `margelet.on_deleted(вызов)` | сообщения удалили |
| `margelet.on_pin(вызов)` | чат закрепляют или открепляют; можно отменить |
| `margelet.button(название, вызов)` | своя строчка в меню чата (три точки) |
| `margelet.on_settings(вызов)` | человек поменял настройку плагина |

Дверей нарочно немного, и каждая названа. Названная дверь переживает
обновление телеграма, потому что за неё отвечаем мы, а не совпадение имён:
поменяется внутренность — поправим мы, а плагин не заметит.

Подменить можно и любой другой метод приложения — про это [ниже](#подмена-любого-метода),
— но это другое обещание. Точнее, это отсутствие обещания: подмена держится
на имени чужого метода, а имя нам никто не гарантировал.

Если нужна дверь, которой нет, — [на форум](https://t.me/margeletforum).
Добавим названную, а не станем открывать все сразу.

### Открыли чат

```python
def on_start():
    margelet.on_chat_opened(сесть_на_поле)

def сесть_на_поле(чат):
    поле = чат.getChatActivityEnterView()
    ...
```

Зовут каждый раз, когда открывается экран переписки, и отдают этот экран.

### Отправка

```python
def on_start():
    margelet.on_send(подписать)

def подписать(текст, чат):
    if текст.startswith("/"):
        return False          # не отправлять вовсе
    return текст + " 🌿"      # уйдёт вот это
```

Что вернуть: строку — она и уйдёт вместо набранного; `False` — не отправлять;
ничего — оставить как есть. Если подписаны несколько плагинов, их зовут по
очереди, и каждый видит текст после предыдущего.

Это единственное событие, которого приложение **ждёт**: пока обработчик
думает, человек смотрит на неотправленное сообщение. Если обработчик думал
дольше десятой доли секунды, в консоли об этом напишут — не в укор, а чтобы
автор знал.

> **Из обработчика отправки нельзя ходить в сеть.**
>
> Это не совет, а предупреждение. Обработчик исполняется на том же потоке,
> который рисует экран: пока идёт запрос, телефон не рисует ничего. Запрос с
> таймаутом в шесть секунд — это шесть секунд замершего приложения, а три
> запроса подряд — восемнадцать.
>
> Обычно андроид ловит такое сам и роняет приложение с понятным объяснением.
> Здесь эта защита не сработает: она живёт в джавовых сокетах, а питон ходит
> в сеть своими, мимо джавы. Ни падения, ни предупреждения — просто замершее
> приложение. Первые два плагина не от нас написаны именно так, и оба автора
> были уверены, что у них всё хорошо.
>
> Как надо — ниже, в «Команде с ответом из сети».

### Команда с ответом из сети

```python
def on_start():
    margelet.on_send(команда)

def команда(текст, чат):
    if текст.strip() != ".погода":
        return None
    margelet.background(lambda: margelet.send(чат, погода()))
    return False        # саму команду в чат не отправляем

def погода():
    ...                 # тут можно и в сеть, и надолго
```

| | |
|---|---|
| `margelet.background(вызов)` | сделать долгое в стороне от экрана |
| `margelet.send(чат, текст)` | отправить сообщение в переписку |
| `margelet.dont_send()` | то же, что вернуть `False` |

Отменить отправку можно тремя способами, и все три равны: вернуть `False`,
позвать `margelet.dont_send()` или `margelet.cancel()` без аргумента. Три
потому, что за отменой тянутся рукой именно к `cancel`, а он до этого значил
только «останови повтор» — и молча ничего не отменял.

### Приход сообщений

```python
def on_start():
    margelet.on_message(считать)

def считать(текст, чат, номер, своё):
    if not своё:
        margelet.log("пришло:", текст)
```

Приходят и свои отправленные — на то и `своё`, чтобы их отличить. Ответ ни на
что не влияет: сообщение уже пришло.

### Своя кнопка в чате

```python
def on_start():
    margelet.button("Посчитать", посчитать)

def посчитать(чат):
    margelet.toast("тут " + str(чат.getMessagesCount()) + " сообщений")
```

Строчка встаёт в меню чата, последней, после всех обычных пунктов: чужой код
не должен раздвигать привычное меню.

Если у одного плагина вызов упадёт, остальных это не отменит: каждого зовут
отдельно, а упавший получает свой разбор в консоли.

`print()` тоже уходит в консоль — перехвачен.

### Удаление сообщений

```python
def on_start():
    margelet.on_deleted(запомнить)

def запомнить(номера, чат):
    margelet.log("удалили", len(номера), "в", чат)
```

Номера — список, `чат` — номер канала или ноль для обычной переписки. Ответ ни
на что не влияет: сообщений уже нет.

Само сообщение к этому времени пропало — прочитать его отсюда нельзя. Кому
нужен текст удалённого, тот должен был запомнить его раньше, в `on_message`.
Двери «покажи, что удалили» не существует и не появится: приложение узнаёт об
удалении в тот же миг, что и вы.

### Закрепление

```python
def on_start():
    margelet.on_pin(не_закреплять_чужое)

def не_закреплять_чужое(чат, закрепляют):
    if закрепляют and чат < 0:
        margelet.toast("каналы не закрепляем")
        return False
```

Вернуть `False` — не закреплять. Это первая дверь не в переписку, а в сам
список чатов.

Приложение ждёт ответа, как и на отправке: пока обработчик думает, человек
смотрит на нажатую кнопку. Долгую работу отсюда уносить в
`margelet.background`.

## Подмена любого метода

Всё, что выше, — двери, которые мы открыли нарочно. Иногда нужного нет, а
ждать нельзя. Тогда — `margelet.hook`: подменить любой метод приложения, как
это делают модули Xposed.

Сначала выключатель: **Настройки → Margy → Плагины → Хуки методов**. По
умолчанию выключено, и это не перестраховка. Кривой хук роняет приложение прямо
при запуске — а выключить его тогда негде, потому что настройки лежат внутри
того самого приложения, которое не открывается.

Защита есть: если запуск с хуками не дожил до конца, следующий поднимется без
них и скажет об этом. Но защита — это сетка, а не обещание, и натянута она под
вами, а не под вашим плагином.

```python
def on_start():
    if not margelet.hooks_work():
        margelet.log("хуков нет:", margelet.hooks_why())
        return

    margelet.hook(
        "org.telegram.messenger.MessagesController",
        "isDialogMuted",
        args=["long", "long"],
        after=показать,
    )

def показать(вызов):
    margelet.log("тихий?", вызов.getResult())
```

| | |
|---|---|
| `margelet.hooks_work()` | поднялись ли хуки вообще |
| `margelet.hooks_why()` | почему не поднялись, если не поднялись |
| `margelet.hook(класс, метод, before=, after=, args=)` | подменить |

`args` нужен, только если метод перегружен, и пишется типами: `"int"`,
`"long"`, `"java.lang.String"`. У обработчика один довод — `вызов`:

| | |
|---|---|
| `вызов.args` | доводы вызова, их можно менять в `before` |
| `вызов.thisObject` | у какого объекта позвали; у статических — `None` |
| `вызов.getResult()` | ответ метода (в `after`) |
| `вызов.setResult(x)` | подменить ответ; в `before` это ещё и отмена вызова |

`margelet.hook` возвращает `False`, если подменить не вышло, и пишет причину в
консоль. Молча делать вид, что подменили, он не станет: плагин, который думает,
что работает, хуже плагина, который честно не работает.

**Чего ждать.** Имена методов телеграма нам никто не обещал: сегодня метод
называется так, завтра иначе, и хук просто перестанет находиться. Поэтому
`hooks_work()` спрашивают до, а не после, и плагин должен уметь обойтись без
хука, а не разваливаться. Рут для этого не нужен: подмена живёт внутри одного
приложения и только пока оно запущено. Другие приложения ей недоступны.

Если хук нужен постоянно и многим — [напишите на форум](https://t.me/margeletforum).
Из хука, который прижился, получается названная дверь, а названная дверь
переживает обновление.

## Свой экран настроек

Плагин не рисует свои экраны — он говорит, из чего экран состоит, а рисует
приложение. Поэтому переключатель у плагина такой же, как везде: та же тема,
тот же цвет, то же нажатие.

```python
def on_start():
    margelet.settings(
        margelet.header("Как здороваться"),
        margelet.switch("hello", "Здороваться", default=True,
                        about="Пишет привет, когда открываешь чат."),
        margelet.text("name", "Имя", default="друг"),
        margelet.choice("mood", "Настроение", ["весело", "спокойно"]),
        margelet.note("Всё это хранится на телефоне и никуда не уходит."),
        margelet.action("Забыть всё", забыть, danger=True),
    )
    margelet.on_settings(поменяли)

def поменяли(ключ, значение):
    margelet.log("теперь", ключ, "=", значение)

def забыть():
    margelet.toast("забыл")
```

| Строка | Что это |
|---|---|
| `margelet.header(текст)` | заголовок раздела |
| `margelet.note(текст)` | пояснение серым |
| `margelet.switch(ключ, название, default=False, about=None)` | переключатель; читается через `margelet.flag(ключ)` |
| `margelet.text(ключ, название, default="", about=None)` | строка, которую вписывают руками; читается через `margelet.get(ключ)` |
| `margelet.choice(ключ, название, варианты, default=None)` | выбор одного из нескольких |
| `margelet.action(название, вызов, danger=False)` | кнопка, которая просто что-то делает |

`settings()` зовут один раз, при запуске. Значения по умолчанию проставляются
сразу же — иначе первое чтение вернуло бы пустоту, хотя человек ничего не
менял.

У плагина с настройками в списке появляется шестерёнка. Нажатие по строке
слева от неё открывает настройки, нажатие по переключателю справа — включает
и выключает сам плагин.

Заявка хранится вместе с памятью плагина, а не в оперативной, поэтому экран
настроек открывается и у выключенного плагина: поправить настройку может
понадобиться до того, как включать.

## Три ловушки на стыке с андроидом

Всё это найдено не в теории, а при написании плагина с играми, и каждая
стоила отдельного захода.

**Цвет — знаковое число.** В java цвет это 32-битное число со знаком, и всё,
что непрозрачно, в нём отрицательное. Питон считает `0xFFFFFFFF` просто
большим числом, и мост в java отказывается его превращать:

```
OverflowError: value too large to convert to int32_t
```

Поэтому цвет надо пересчитывать:

```python
def argb(value):
    return value - 0x100000000 if value > 0x7FFFFFFF else value

view.setTextColor(argb(0xFFFFFFFF))
```

Падает это на первом же цвете, то есть экран не появляется вообще, и по виду
не отличить от «плагин не запустился».

**Список питона — не массив java.** Если метод ждёт массив, список ему не
подойдёт:

```python
from java import jarray
from java.lang import CharSequence

titles = jarray(CharSequence)(["Первое", "Второе"])
```

**Экран трогать только с главного потока.** Событие `on_send` уже на нём, а
вот кнопка на экране настроек — нет. Оттуда любое окно надо открывать через
`margelet.ui`, иначе не откроется ничего.

Ошибки такого рода видны только в консоли: Настройки → Margelet → Плагины →
Консоль. Там будет и строка, и причина.

## Что доступно кроме этого

Питон здесь настоящий, с доступом к java-классам приложения:

```python
from java import jclass

Config = jclass("org.telegram.margelet.MargeletConfig")
margelet.log("ватермарка:", Config.watermarkOnSend())
```

Отсюда достаётся всё остальное приложение. Это и есть «плагин может всё» —
не оборот речи.

## Консоль

Настройки → Margelet → Плагины → Консоль. Туда уходит вся печать плагинов и
их ошибки, ошибки красным. Питон падает молча, так что без консоли о своей
опечатке автор узнаёт только по тому, что «ничего не работает».

## Установка

Настройки → Margelet → Плагины → Установить из файла. На окне установки видно
автора и заявленные разрешения.

Ещё можно нажать на файл `.marp` прямо в чате — приложение предложит его
поставить.

На окне установки есть две кнопки. «Поставить» ставит плагин выключенным.
«Поставить и включить» ставит, включает и сразу перезапускает Margelet —
плагин начинает работать, не дожидаясь, пока приложение закроют вручную.

Если плагин заявил `min_version` выше вашей, он не поставится, и вам скажут,
какая версия нужна, — вместо того чтобы поставиться и сломаться.

На окне установки есть кнопка «Посмотреть архив»: она открывает `.marp` тем,
что на телефоне умеет архивы, — прочитать код можно до установки, а не после.
Правило форума требует, чтобы код был открыт; значит, и открыть его должно
быть чем.

Долгое нажатие на строку — карточка плагина и удаление.

Выключение значит «больше не запускать». Уже работающий питоновский код
остановить нечем — он доживёт до перезапуска приложения. Поэтому на экране
плагинов есть кнопка «Перезапустить Margelet»: выключили — нажали — плагина
больше нет.
